# Resume Builder System

## Project Name

Resume Builder System

## Category

Full-Stack Web Application, Resume Generation, Secure Document Storage

## Problem Statement

Enable users to generate professional resumes by entering education, skills, and experience through structured forms.

- MySQL
- PyAES
- PBKDF2
- Matplotlib
- OpenCV

- Dynamic resume rendering using Matplotlib

## Key Features

- Full-stack web application.
- Structured forms for education, skills, and experience.
- Professional resume generation.
- Server-side encrypted storage for generated resumes.
- Decrypt-on-download functionality.
- Customizable fonts.
- Structured resume sections.
- Photo embedding.
- Output resizing to standard document dimensions of 1222 x 2601 px.
